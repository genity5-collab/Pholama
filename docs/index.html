Get Pholama for your PC

Bigger models, web search and tools. Nothing to install first: it brings its own small Node.js if your PC has none. Open a terminal and paste one line:
Any system
npx github:genity5-collab/Pholama
Windows (PowerShell), saves a Pholama folder
irm https://raw.githubusercontent.com/genity5-collab/Pholama/main/install/install.ps1 | iex
Mac / Linux
curl -fsSL https://raw.githubusercontent.com/genity5-collab/Pholama/main/install/install.sh | bash
Or download the zip, unzip, and double-click start.bat. Then open http://localhost:11435.

API keys for this PC

Give one key to each phone or app. Revoke a key and that device stops working right away.
API keys can only be created or revoked on the PC itself.

Safety

Data Privacy & Safety Checklist:

  • On-device processing: Local models run on your PC. Chats and history stay in this browser.
  • Local Storage: Tokens, remote keys, settings, and sessions are stored in this browser only.
  • GitHub writes: GitHub write actions always prompt for explicit Allow / Deny.
  • Remote Connection: API keys are sent directly to your configured PC endpoint.

Chat history

Chat history is stored locally on this device and never leaves your browser.
